# Telegram Business Auto-Responder Bot (aiogram 3.x)

Полнофункциональный, асинхронный Telegram-бот на базе **aiogram 3.x** и **Python 3.11+**, работающий через режим **Telegram Business (Чат-боты)** от лица вашего личного аккаунта.

Бот автоматически отвечает в личных диалогах на триггерные фразы:
1. **Триггеры собеседника**: когда вам пишут «скинь карту», «скинь карту плиз», «номер карты» и т.п., бот мгновенно отправляет номер вашей банковской карты в формате `<code>...</code>` (копирование в один клик).
2. **Триггеры владельца**: когда вы сами отправляете короткую команду в чат (например, `.card`, `.hello`, `.thanks`), бот отправляет заранее заготовленный ответ, а ваше исходное сообщение с триггером автоматически удаляет (или редактирует), делая диалог чистым.

## 🚀 Пошаговое руководство по настройке

### 1. Создание бота в @BotFather
1. Откройте диалог с официальным ботом [@BotFather](https://t.me/BotFather) в Telegram.
2. Отправьте команду `/newbot`.
3. Задайте имя бота (например, `My Business Assistant`) и юзернейм, оканчивающийся на `bot` (например, `my_business_helper_bot`).
4. Скопируйте полученный **HTTP API Token**.

### 2. Включение Business Mode в @BotFather
> ⚠️ **Критически важно!** Без этого шага Telegram не позволит подключить бота как бизнес-ассистента в настройках аккаунта.

1. В [@BotFather](https://t.me/BotFather) отправьте команду `/mybots` и выберите созданного бота.
2. Нажмите **Bot Settings** → **Business Mode** (или **Turn on Business Mode**).
3. Убедитесь, что статус изменился на **Business Mode: Turned ON**.

### 3. Подключение бота к вашему личному аккаунту Telegram
> ℹ️ **Требование:** Владелец аккаунта должен иметь активную подписку **Telegram Premium**, так как Telegram Business доступен премиум-пользователям.

1. В приложении Telegram на смартфоне или Desktop откройте:
   - **Настройки** → **Telegram Business** (или **Бизнес**) → **Чат-боты** (**Chatbots**).
2. В строке поиска введите юзернейм вашего бота (например, `@my_business_helper_bot`) и выберите его.
3. Настройте разрешения:
   - **Управлять чатами**: выберите чаты, в которых бот должен работать (например, «Все личные чаты» или исключите определенные контакты).
   - Включите галочку **Отвечать на сообщения** (*Reply to messages*).
   - Включите галочку **Управлять сообщениями** / **Удалять отправленные сообщения** (*Can delete sent messages*), чтобы бот мог автоматически удалять ваши команды `.card` и др.
4. Нажмите **Готово** / **Сохранить**.

## 💻 Установка и запуск

### Локальный запуск

1. **Клонируйте репозиторий / перейдите в папку проекта:**
   ```bash
   cd telegram_auto
   ```

2. **Создайте и активируйте виртуальное окружение Python (3.11+):**
   ```bash
   python -m venv .venv

   # Windows:
   .venv\Scripts\activate

   # Linux / macOS:
   source .venv/bin/activate
   ```

3. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Создайте файл `.env` на основе `.env.example`:**
   ```bash
   cp .env.example .env
   ```

   Заполните переменные:
   ```ini
   # Токен от @BotFather
   BOT_TOKEN=1234567890:ABCdefGhIJKlmNoPQRsTUVwxyZ_1234567

   # Ваш цифровой Telegram ID (узнать можно у @userinfobot)
   OWNER_ID=123456789

   # Номер вашей банковской карты
   CARD_NUMBER=2202 2024 1234 5678

   # Удалять сообщение владельца с триггером (.card и т.д.)
   DELETE_TRIGGER_MESSAGE=true

   # Защита от спама: кулдаун в секундах на повторное срабатывание в одном чате
   COOLDOWN_SECONDS=30

   # Путь к файлу базы данных SQLite
   DB_PATH=bot_data.sqlite3

   # Уровень логирования (DEBUG / INFO / WARNING)
   LOG_LEVEL=INFO
   ```

5. **Запустите бота:**
   ```bash
   python -m bot.main
   ```

### Развертывание на сервере VPS (systemd service)

Для стабильной работы 24/7 настройте службу `systemd` на Ubuntu / Debian:

1. Перенесите код на сервер, например в каталог `/opt/telegram_auto`.
2. Создайте виртуальное окружение и установите зависимости:
   ```bash
   cd /opt/telegram_auto
   python3 -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ```
3. Создайте файл сервиса `/etc/systemd/system/tg-business-bot.service`:
   ```ini
   [Unit]
   Description=Telegram Business Auto-Responder Bot
   After=network.target

   [Service]
   Type=simple
   User=root
   WorkingDirectory=/opt/telegram_auto
   ExecStart=/opt/telegram_auto/.venv/bin/python -m bot.main
   Restart=always
   RestartSec=5
   EnvironmentFile=/opt/telegram_auto/.env

   [Install]
   WantedBy=multi-user.target
   ```
4. Активируйте и запустите службу:
   ```bash
   sudo systemctl daemon-reload
   sudo systemctl enable tg-business-bot
   sudo systemctl start tg-business-bot
   ```
5. Просмотр логов в реальном времени:
   ```bash
   journalctl -u tg-business-bot -f
   ```

## 🛠 Управление ботом, триггерами и должниками

Все настройки производятся в **личном диалоге с самим ботом** (не в бизнес-чатах). Доступ к командам управления открыт только владельцу с `OWNER_ID`.

### 💳 Учёт задолженностей (отправка сообщений ЧЕРЕЗ ВАШ АККАУНТ):
> 🌟 **Главная особенность:** должнику **НЕ нужно** заходить в бота или нажимать `/start`! Все сообщения приходят должнику **от вашего личного имени** прямо в ваш личный диалог с ним в Telegram (через Telegram Business).

- **Управление через бота в ЛС:**
  - `/debts` — просмотр всех должников на учете с кнопками:
    - 🔔 **Напомнить сейчас** — моментальная отправка уведомления должнику от вашего имени.
    - ✅ **Снять с учета (погашен)** — закрытие долга с отправкой от вашего имени сообщения: *«Долг успешно закрыт! Претензий больше нет. Спасибо!»*.
    - 🗑 **Удалить запись** — удаление из базы данных.
  - `/add_debt` — пошаговый мастер постановки должника на учет (пересылка сообщения от человека, ввод Telegram ID или @username).

- **Быстрое управление прямо из диалога с человеком:**
  - Напишите в чате с человеком: `.debt 5000 за аренду до пятницы` (или `.долг 5000 ...`) — бот автоматически поставит человека на учет, удалит вашу сервисную команду и отправит подтверждение.
  - Напишите в чате с человеком: `.closedebt` (или `.долгзакрыт` / `.payed`) — бот закроет долг и от вашего имени напишет, что долг закрыт.

- **Автоматическая рассылка:** Каждый день ровно в 12:00 (настраивается в `.env`: `NOTIFICATION_HOUR=12`, `NOTIFICATION_MINUTE=0`, `TIMEZONE=Europe/Moscow`) сервис отправляет всем активным должникам личные сообщения от вашего имени, а вам в боте присылает краткий отчет.

### ⚡️ Telegram Business & Триггеры автоответов:
- `/start` — главное меню с кнопками.
- `/status` — проверка подключения к Telegram Business, права ответов и удалений.
- `/list_triggers` — просмотр всех активных правил с кнопками быстрого удаления.
- `/add_trigger` — интерактивный FSM-диалог добавления нового триггера:
  1. Ввод слова/фразы (например, `скинь реквизиты`, `.promo`).
  2. Выбор адресата: `👤 Собеседник` / `👑 Владелец` / `👥 Оба`.
  3. Выбор типа проверки: `🎯 Точное совпадение (exact)` или `🔍 Поиск подстроки (contains)`.
  4. Ввод текста ответа (с поддержкой HTML и тега `{CARD_NUMBER}`).
- `/del_trigger <слово_или_id>` — быстрое удаление триггера.
- `/cancel` — отмена любого текущего диалога.

### Предустановленные триггеры из коробки:
При первом запуске база данных автоматически инициализируется следующими правилами:
1. **Для собеседника** (поиск подстроки, без учета регистра и знаков препинания):
   - `скинь карту`
   - `кинь карту`
   - `дай карту`
   - `номер карты`
   *(Сработает и на: «скинь карту плиз», «привет! скинь карту, пожалуйста»)*
   Ответ:
   ```html
   Номер карты:
   <code>2202 2024 1234 5678</code>
   ```
2. **Для владельца** (точные команды с удалением триггера):
   - `.card` ➔ Отправляет моноширинный номер карты.
   - `.hello` ➔ Отправляет приветственное сообщение.
   - `.thanks` ➔ Отправляет вежливую благодарность.

## ⚠️ Частые проблемы и нюансы (Pitfalls)

1. **Бот не получает обновления бизнес-сообщений (`business_message`):**
   - По умолчанию Telegram Bot API **не присылает** бизнес-апдейты в polling. В коде `bot/main.py` параметр `allowed_updates` настроен явно:
     `allowed_updates=["message", "business_connection", "business_message", ...]`
   - Убедитесь, что в `@BotFather` включен **Business Mode** (пункт 2 инструкции выше).

2. **Ошибка `business_connection_id is missing`:**
   - Все методы отправки (`send_message`, `send_photo` и т.д.) от имени вашего аккаунта требуют обязательной передачи аргумента `business_connection_id=message.business_connection_id`. В противном случае Telegram отправит сообщение в личный чат от имени бота, а не от вашего имени.

3. **Бот не может удалять сообщения владельца (`DELETE_TRIGGER_MESSAGE`):**
   - В настройках *Telegram → Настройки → Бизнес → Чат-боты* у бота обязательно должно быть включено разрешение **«Удалять отправленные сообщения»**.
   - Если право отсутствует, бот перехватывает `TelegramBadRequest` и безопасно пробует отредактировать сообщение триггера, не вызывая сбоя программы.

4. **Зацикливание автоответчиков (Infinite Loops):**
   - Когда бот отправляет сообщение через Business API, Telegram присваивает полю `sender_business_bot` объект бота. Бот сразу отсекает такие сообщения, а также отслеживает недавние хэши ответов (`LoopGuard`).

5. **Требование к подписке Telegram Premium:**
   - Функция подключения сторонних чат-ботов к личному профилю (Telegram Business) на стороне Telegram доступна только владельцам учетных записей с **Telegram Premium**.
